---
name: Match location map links
description: Product choice for opening saved match locations in map apps.
---

Match locations remain plain-text venue or address fields, with Apple Maps and Google Maps directions available from the saved text. Do not add venue autocomplete or require a maps API provider unless the product owner changes this choice.

**Why:** The product owner chose directions links instead of place search to keep location entry simple and avoid provider setup.

**How to apply:** Preserve plain-text locations and offer both map destinations wherever match locations are shown.
